# Card index

Every card carries a plain number on screen (toggle in the grown-ups' area).
Ranges say which deck it came from:

| Range | Deck |
|---|---|
| 1–999 | Photos |
| 1000–1999 | Drawings |
| 2000–2999 | Words |
| 3000–3999 | Sentences |
| 4000–4099 | Letters |
| 4100–4199 | By Heart |
| 5000–5999 | Blending |

Numbers come from content order, so they are stable across shuffles, launches
and devices. They shift only if the content file is reordered.
