# Card index

Every card shows a plain number (toggle in the grown-ups' area). Ranges say which deck:

| Range | Deck |
|---|---|
| 1–999 | Photos |
| 1000–1999 | Drawings |
| 2000–2999 | Words |
| 3000–3999 | Sentences |
| 4000–4099 | Letters |
| 4100–4199 | By Heart |
| 5000–5999 | Blending |

Numbers come from content order and are stable across shuffles and launches.
**They shift whenever photos are added or removed** — regenerate this file after any
change, and re-check an older list of numbers against it.
